# combine with diffusers 0.42.0. transformers 5.20.2 is from the
# same verified set as the Z-Image app. sentencepiece is pinned
# because the text-encoder tokenizer files may need it.
#
# No gguf pin here: this app never loads a .gguf file (the Z-Image
# app needed gguf; this one loads the plain Diffusers pipeline).

# verified end-to-end with pip's resolver (dry run, Windows

# metadata, NOT from the same dry run -- and here is why: a
# full-set dry run launched from a Linux host CANNOT resolve any
# torch-dependent package for a Windows target, because pip
# evaluates torch's Linux-only nvidia-nccl markers against the
# Linux host and reports a conflict. On Alan's real Windows
# machine this artifact does not exist: install.bat installs
# torch from the cu130 index FIRST, and accelerate 1.15.0 needs
# only torch>=2.0.0, numpy, packaging, psutil, pyyaml,
# huggingface-hub>=0.21.0, and safetensors>=0.4.3 -- all
# satisfied by the cu130 torch step plus the pins below. Do not
# "re-verify" this file with a Linux-host cross-platform dry run
# and panic at the torch conflict; it is the dry run that is
# broken, not this file.
